This is my knowledgebase on FDM printing: the physics, the material science and the control theory
behind it, written casually, starting in plain English and working up to the math. It grew out of
rebuilding my Voron 2.4 on Kalico and wanting to understand why every setting is what it is,
instead of copying numbers from someone else's profile.

Some of it is well established and linked to the papers that showed it. Some of it is my own theory.
I say which is which.

## What's in here

```text
.
├── handbook/        # 13 chapters: polymers, melting, extrusion, layer bonding, warp, motion, heat, estimation, materials
│   └── figures/     # the plots, generated by make_figures.py
├── research/        # reading notes: materials, control, and ideas borrowed from other industries
├── calibration/     # variables, sensors, models, filament library, and the slicer as part of the machine
├── guides/          # practical how-tos
└── tools/           # doc checks (LaTeX quirks, links, dashes)
```

## Status

Work in progress, and it'll stay that way. My test results live in my lab notes, which go public
once they're cleaned up. The printer itself (its config and build log) lives in a private repo,
since it holds machine backups.
